
# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Create a Hangman game where players guess letters to reveal a hidden word before running out of attempts. You'll practice string manipulation, loops, conditionals, and random selection.

## 📝 Tasks

### 🛠️ Build the Hangman Game

#### Description

Develop a complete Hangman game that randomly selects a word from a predefined list and allows players to guess letters. The game should track incorrect guesses and display the current state of the word as players make progress.

#### Requirements

Completed program should:

- Randomly select words from a predefined list
- Accept letter guesses and show current progress (e.g., `_ _ _ _ _` format)
- Track incorrect guesses remaining and display remaining attempts
- End when the word is guessed or attempts are exhausted
- Display clear win/lose messages with appropriate feedback
